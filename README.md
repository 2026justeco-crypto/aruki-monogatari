# 歩く物語（試作）

歩いた距離でレベルが上がり、観光名所に着くとその場所の物語が始まる、という案の試作画面です。

1本目は京都府・鹿苑寺（金閣寺）と足利義満。ナレーションと義満の台詞が交互に進みます。画面のどこかを押すと次へ進みます。

- 音声はまだ入っていません（台本は `logs/docs/stories/01-kyoto-kinkakuji.md` に番号つきで分けてあります）
- 背景は写真ではなく、こちらで描いた絵です。寺社の写真は商用利用に許諾が要る場合があるため、まず絵で形にしています
- 上部の「歩いた距離」「語り部レベル」は表示の見本で、まだ動きません

## 物語の作り方の決まり

- 事実と解釈を分ける。史料で確かめられないことは、ナレーション側で「後の世の人の見方です」と断る
- 出典は台本ファイルの末尾に必ず書く
- 学校で使われる前提なので、誤りを残さない
